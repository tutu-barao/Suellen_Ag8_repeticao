Exercício da Agenda 8 de Desenvolvimento de Sistemas

## Desenvolver um programa em Python utilizando a estrutura de 
repetição para coletar e exibir o retorno de uma pesquisa de atendimento ao cliente

##  Funcionalidades
- Coleta de **nome**, **idade** e **opinião** de cada entrevistado
- Validação robusta de entrada (idade e opinião)
- Classificação automática das respostas:
  - `1` → EXCELENTE
  - `2` → BOM
  - `3` → RUIM
- Relatório final com quantidade de respostas EXCELENTE e RUIM
